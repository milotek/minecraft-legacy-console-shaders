## description
Re-live your childhood with these shitty shaders. Tested for 1.6.4 edition using ShadersModCore. Probably works on any version using OptiFine or Iris.
If you are weird like me and play old versions of minecraft, back before when OptiFine shipped with built-in shader support, you are going to have to download this weird mod from ages ago called ShadersModCore.
You can use this in conjunction to OptiFine - not to worry.

Recommended Mods for 1.6.4 Forge + Prism Launcher:
1. [OptiFine for 1.6.4](https://optifine.net/adloadx?f=OptiFine_1.6.4_HD_D1.jar)
2. [ShadersModCore](https://www.minecraftforum.net/forums/mapping-and-modding-java-edition/minecraft-mods/1286604-shaders-mod-updated-by-karyonix)
3. [LegacyFix (MultiLoader)](https://github.com/betacraftuk/legacyfix/tree/multiloader)
